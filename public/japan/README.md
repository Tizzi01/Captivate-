# Japan gallery

Five files, referenced from the `trip to Japan` gallery in `src/data/site.ts`.
Save them here with exactly these names:

| File | What it is |
| --- | --- |
| `invite.png` | The invitation email to the Shiba Arcade exhibition |
| `arcade.jpg` | The build photo from Spacebar Studio |
| `room.jpg` | The photo of someone asleep at the venue |
| `couldnt-go.png` | The list of people who bought tickets and could not go |
| `la-peace.gif` | The la peace meme |

Any file that is missing is dropped from the gallery rather than showing a
broken frame, so the page is fine until they are all in place. Change the
names, the order or the captions in the `images` array in `src/data/site.ts`.
